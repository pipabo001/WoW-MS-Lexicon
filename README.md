# WoW-MS-Lexicon

《魔兽世界》**微软拼音「用户自定义短语」**词库。

打游戏聊天、看攻略时，直接输入拼音即可优先打出：`奶德`、`大秘境`、`时光漫游` 等系统词库常缺的专有名词。

> **版本更新会发新的整合包**：资料片 / 补丁 / 赛季有新专有名词时，本仓库会更新 `.dat` 整合包（Release 或主分支文件）。请重新「导入」覆盖即可。

## 更新时怎么导入（避免重复）

微软拼音自定义短语导入多为**追加/合并**，同一整合包叠导可能重复。**建议：先清除之前导入的游戏短语，再导入新的整合包。**

1. 设置 → … → 微软拼音 → 词库和自学习 → **自定义短语**
2. （可选）先**导出**备份
3. 删掉旧的游戏相关短语，或清空后只保留你自己的短语
4. **导入**新的 `.dat` 整合包

---
## 导入（Win10 / Win11）

1. 下载 `wow-microsoft-pinyin.dat`
2. 设置 → 时间和语言 → 语言和区域 → 中文（简体）→ 语言选项 → 微软拼音 → 词库和自学习 → **自定义短语** → **导入**
3. 切换输入法后试：`naide` → 奶德

官方批量导入只要二进制 `.dat`（文件头 `mschxudp`），**不支持**纯 TXT 直接导入。同目录 `.txt` 供第三方工具（如 PinyinLexTool）使用。
