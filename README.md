# WoW-MS-Lexicon

《魔兽世界》**微软拼音「用户自定义短语」**词库。

打游戏聊天、看攻略时，直接输入拼音即可优先打出：`奶德`、`大秘境`、`防战`、`至暗之夜` 等系统词库常缺的专有名词；同时覆盖搜狗细胞词库《魔兽世界》中的大量物品 / NPC / 地名译名。

> 许可证：**MIT**（见 `LICENSE`）。游戏专有名词的商标与版权归暴雪 / Blizzard 所有；本仓库仅提供玩家常用中文译名与俗称的输入法短语整理，不包含游戏资源文件。

---

## 可导入文件

| 文件 | 用途 |
|------|------|
| **`wow-microsoft-pinyin.dat`** / **`wow.dat`** | **推荐**：设置里「导入」自定义短语 |
| `wow-microsoft-pinyin.txt` / `wow.txt` | UTF-8；给 [PinyinLexTool](https://github.com/mchudie/PinyinLexTool) 用 |
| `wow-microsoft-pinyin-utf8bom.txt` | 同上，带 UTF-8 BOM |

TXT 行格式：`拼音<TAB>候选位置<TAB>词语`

## 更新时怎么导入（避免重复）

微软拼音自定义短语导入多为**追加/合并**，同一整合包叠导可能重复。**建议：先清除之前导入的游戏短语，再导入新的整合包。**

1. 设置 → … → 微软拼音 → 词库和自学习 → **自定义短语**
2. （可选）先**导出**备份
3. 删掉旧的游戏相关短语，或清空后只保留你自己的短语
4. **导入**新的 `.dat` 整合包

> 本版词条量显著增大（约五万条）。叠导旧版极易重复，**务必先清旧再导入**。

## 导入步骤（Win10 / Win11）

1. **设置** → **时间和语言** → **语言和区域**
2. 中文（简体）→ **选项** → **微软拼音** → **选项**
3. **词库和自学习** → **添加或编辑自定义短语** → **导入**
4. 选择本仓库的 `wow-microsoft-pinyin.dat`（或 `wow.dat`）
5. 切换一下输入法使短语生效；测试输入 `naide` 应出现 **奶德**

导入前建议先导出备份自己的自定义短语。

---

## 格式要点

- 文件头魔法字：`mschxudp`
- 拼音与词语在 `.dat` 内为 **UTF-16 LE**
- 拼音 ≤32、不以 `u`/`v` 开头、仅 `a-z`；词语 ≤64；候选位 1–9

| 搜狗细胞词库并入条目 | 49219（新词语 49213；与俗称表重叠跳过 389） |

**数据来源**

1. 本仓库维护的实用俗称 / 指挥口令 / 赛季词（`source/wow_words.py`）——优先保留，含 `naide→奶德` 等缩写触发。
2. 搜狗细胞词库 **《魔兽世界》**（网络游戏 / 官方推荐，网友上传，约 1.8MB `.scel`，原始 49718 条；过滤拼音/词长后 49608 条）——整包并入，补全物品、NPC、地名等百科向译名。

覆盖范围：经典 → TBC → WLK → … → 地心之战 → 至暗之夜；职业/专精俗称、副本/大秘/地下堡、指挥口令，以及细胞词库中的大量专有名词。

暗黑破坏神词库见独立仓库 **Diablo-MS-Lexicon**（本 `.scel` 经抽样判定为纯魔兽，未并入暗黑包）。

## 版本与更新

**版本更新会发布新的整合包**（重新导出的 `.dat` / `.txt`），请直接下载最新 Release 或主分支产物；导入前先清旧。不会做增量补丁格式。

## 本地重新构建

```bash
python3 -m venv .venv
.venv/bin/pip install pypinyin
.venv/bin/python build.py
```

需要 `source/wow_words.py`、`source/scel_wow.txt` 与 `tools/mschxudp_file.py`。
